Entry for the [Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4) bounty on make.fun. The program writes one emoji to `/output/entry.txt`.

## The entry

> 🧞

1 character, 4 bytes UTF-8, no trailing newline. Gate: 1 to 16 characters.

## Why this glyph

An agent is a genie. You summon it with a wish, it does the work, then it is gone until the next wish. It reads at a glance, it is a familiar shape at small size, it says how the agent works (acts on a request), and it is not the robot or smiley half the field will send.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only. No network, no secrets, no input files.
